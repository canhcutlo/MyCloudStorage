================================================================================

4. SEMANTIC SEARCH (Vietnamese Support)
   - Vietnamese accent normalization
   - Matches files written without accents
   - Common abbreviations recognition:
     * T10, T.10 → tháng 10 (October)
     * BC → báo cáo (report)
     * TC → tài chính (financial)
     * HD → hợp đồng (contract)
     * KH → kế hoạch (plan)
     * Q1-Q4 → Quarters
   - Token-based similarity matching
   - Relevance scoring
   - Number-aware search for dates
   - Separator normalization (underscores, hyphens, dots)
   - Filter by file type (Files/Folders)

5. SORTING FEATURES
   - Sort by Name (A-Z / Z-A)
   - Sort by Date (Newest First / Oldest First)
   - Sort by Size (Smallest First / Largest First)
   - Folders always appear before files
   - Persistent sort preferences in URL
